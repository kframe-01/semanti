# Test Intent

## Definition

A description of the purpose, subject under test, and intended outcome of a test, expressed in language that domain stakeholders can review and refine into requirements and verification criteria.

## Usage

A Product Owner describes a Test Intent before a Testing Engineer turns it into a position-specific test sequence.

## Boundaries

- Includes: The intended behavior, relevant conditions, and expected result of the test.
- Does not include: The implementation details of a runnable sequence or station-specific hardware configuration.
