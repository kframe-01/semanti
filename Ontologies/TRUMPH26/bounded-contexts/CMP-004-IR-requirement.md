# Requirement

## Definition

A structured statement of a need or expected behavior refined from a Test Intent so that it can be reviewed and verified.

## Usage

The accepted Test Intent is refined into requirements and verification criteria.

## Boundaries

- Includes: The need and expected behavior to be satisfied.
- Does not include: The implementation of a test sequence; the required structure is still to be agreed.
